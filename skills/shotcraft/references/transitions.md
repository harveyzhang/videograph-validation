# transitions.md — 转场体系（通用）

转场分三层：**剪辑层**（切点怎么选）、**引擎层**（相邻镜头重叠时怎么合成）、
**协议层**（相邻镜头互相构造对方首帧的 handshake）。第三层才是重心。

---

## 1. 剪辑层：切点原则

```
切点(行) = 行首词 start 所在（或之前）的最后一个拍      # 永不切在词中间
```
- 辅助：`after(行)` = 行尾最近的 downbeat（instrumental 段用）；段起点 = 分析出的 section 边界。
- **窗口相触 = 硬切**——节拍驱动视频的默认转场。叠化只在"换世界失败"时兜底。
- 切点的三种味道（都在拍上，观感不同）：
  1. **运动顶点切**：上一板切在运动最快处（俯冲最快点/翻滚过冲中），下一板静止开场——
     动与静的反差就是转场。
  2. **静止交接切**：出口最后 ~0.1s 强制清零 shake/zoom/CA，把完全静止的几何交给下一板。
  3. **闪光切**：`flash` 0.9–1.2 换世界级白闪（注意：flash 是加性线性的，日常必须 ≤0.05，
     只有"换世界"时刻才用大值，用完立刻回日常量级）。

## 2. 引擎层：重叠合成机制

任何确定性视频引擎都可以实现这三个原语（pdoom 引擎与 VideoGraph 全引擎管线同源）：

| 原语 | 语义 |
|------|------|
| 相触硬切 | `t ∈ [start,end)` 只有一个活跃镜头；`prev.end == next.start` |
| 交叉叠化 | 窗口重叠时按 `tin = (t−start)/(prev.end−start)` mix 前板纹理 |
| 自转场 | 镜头声明 `handlesTransition`，自己拿到前板纹理 `under` 自行合成（拖影/位移/形变转场用） |
| 全帧后期转场 | `fade`（压黑）/ `flash`（白闪）/ `zoom` / `invert` 作为镜头返回值，由引擎统一施加 |
| paper/明暗模式 | 通知 UI 层换配色（亮底板切换也是转场的一部分） |

VideoGraph 平台上这两者的对应：全引擎管线=引擎自动叠化+镜头自转场+`project_transition_configure`
（cut/dissolve/wipe/dip 四种参数化转场）；工坊 mini-engine 没有引擎级转场——**转场全部由相邻
镜头的首末帧自己完成**（见协议层），这是工坊卡片的默认工作方式。

## 3. 协议层：handshake 目录（转场的真正内容）

**核心思想：出口产物 = 入口产物。** 上一板最后一帧里放一个"交接物"，下一板第一帧从它开始。
按可靠性递增的四种实现手段：

1. **字面常量握手**：两侧各自硬编码同一组屏幕/世界坐标（`HANDOFF=(1045,600)`、`THREAD.y=629`、
   `CARET=(x,y)`）。最简单，改一侧要同步另一侧（范例：pdoom hook.ts 明言 "copied, not imported"）。
2. **投影函数复刻**：A 板复刻 B 板的相机/投影函数，把 B 板某物的世界坐标投到屏幕，
   让自己的笔/火花精确滑到那个点（范例：open 的 `lossHandoff()`）。
3. **共享模块**：两侧 import 同一个布局模块（函数返回每字母的屏幕仿射+抖动参数），
   切割瞬间逐像素一致（范例：pdoom `room-shrooms.ts`）。
4. **实时共享渲染**：A 板内部直接渲染 B 板的场景/世界类当自己的底层，切点处两板画面相同
   （范例：loom 的 Droste 底层直接渲染 IlyaRoom）。

### 交接物类型库（选一个用）

| 交接物 | 做法 | 范例 |
|--------|------|------|
| **火花/线**（万能总线） | 一条贯穿多板的橙线+火花头：A 板出口把线引到 B 板入口坐标；B 板以 `s<0` 引线开场 | open→loss→…→stack；paperclips 引线 |
| **轮廓/文字遗产** | A 板把某字排干填充只剩 outline+白热，B 板开场把它打碎成 debris | hook1→room |
| **几何压扁** | A 板出口把仪表/图形 rotate+scale 压扁成 B 板的某形状（眼缝/中线） | hook2→ascent 眼缝 |
| **拉平成线** | A 板把整串元素压成一条线（宽→全屏、高→0.003），B 板以这条线为骨架 | hook4→loom 纬线 |
| **形态 morph** | A 板尾把元素连续变形为 B 板首的元素（菱形→光标：路径 lerp+dash 收拢成实线） | leftturn CDR 槽→prompt caret |
| **状态坍缩** | A 板整体压扁成一条亮线（squash 进 ray 生成与 UI），B 板从这条线开始 | shoggoth CRT flatline |
| **中心点火花** | A 板把光坍缩到画面中心+末帧落火花，B 板拍 0 引爆它 | ilya→outro |
| **预渲染接力** | A 板尾提前渲染 B 板的局部（光池/尘点）淡入，或整帧实时渲染 B 板当底层 | leftturn uPool；loom→ilya |
| **白场/黑场接力** | A 板出口 flash 到白，B 板入口保持白底接住（或反向用 fade 压黑） | prompt→hook1 |

### 动效级转场语法（板内小转场/段内切换）

- **match-cut 屏幕锚定**：两镜头间缩放同时插值屏幕锚点，让"同一物体"切点前后屏幕位置不动
  （`cam.y = 目标世界y − (H/2 − sy)/zoom`）。缝合多乐章的万能胶。
- **dive match-cut**：以某个字形/物体的局部为 pivot 冲进去（zoom ×N+平移 pivot→画面中心+roll
  到 B 板开场角），B 板从 macro 拉出。
- **角度握手**：相邻板共享一组 roll/pitch 常量（A 的出角=B 的入角），多板链式互认。
- **whip-pan**：快门内两个相机位姿间 multi-tap 采样（shader 里 ≤16 位姿，或 Canvas2D 里多份
  偏移重绘）；`cutBetween` 守卫——剪切点附近禁用模糊，防跨切糊。
- **撕纸/破碎**：三倍频锯齿撕裂线+飞丝+断口白边+两半坠落（旋转+缩小+抛物线）+压黑。
- **时间重映射**：把源区间快放 N 遍（`remap(t)→{时间,循环号}`，内容函数无感知）做 stutter/回放。
- **倒带**：预渲染静帧加速倒放+旧化（duotone/RGB 分离）=廉价；真实场景实例以 `τ=(1−prog)²`
  倒放刹车停在第一帧=无缝循环。

## 4. 工具速查（写转场时）

| 想要 | 用 |
|------|-----|
| 硬切 | 窗口相触（默认），切点=行首词所在拍 |
| 叠化 | 窗口重叠（引擎自动）；要自己控制就 handlesTransition+合成 under |
| 压黑/淡入 | fade 返回值 |
| 白闪 | flash 返回值（日常 ≤0.05，换世界 0.9–1.2） |
| 冲击 | shake/zoom/exposure = `Σ amp·pulse(t,事件,τ)`，方向乘 hash/噪声 |
| 运动模糊交接 | whip multi-tap 或逐线段重画；剪切点 cutBetween 守卫 |
| 跨板构图对齐 | 字面常量 / 复刻投影 / 共享模块 / 实时共享渲染（可靠性递增） |
| 交接物 | 上表 9 种：出口产物=入口产物 |
| 回放/倒带 | 预渲染静帧+旧化（廉价）；实例倒放刹车（真） |
