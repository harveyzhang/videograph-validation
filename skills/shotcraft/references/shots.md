# shots.md — 17 种分镜范式库

按"这镜想讲什么/什么情绪"选范式。每条：适用 → 视觉构成 → 关键手法 → 最简实现 →
范例（pdoom-video 文件，逐行拆解看范例源码）。

通用骨架（所有范式共用）：
`init/构造期` 把歌词行/词/拍换算成事件表 → `render(t)` 纯函数求值 → 层次合成
（背景 pass → 线/几何 → 文字层 → 火花/特效层）→ 返回后期覆盖（shake/zoom/flash…）。

---

## 1. 施工图笔绘板（plotter sheet）
**适用**：开场/元叙事——"画出来"的过程本身就是内容。
**构成**：坐标纸/网格底 + 一支会飞的"笔"（火花原型）+ 逐笔出现的图形 + 单笔画字注记。
**手法**：笔画系统（每条笔画存弧长表+绘制窗口；对 ease 做二分逆函数得"笔头到达每点的时刻"，
刻度/标注在笔经过时才落下）；笔模拟（笔画间补快移段，任意 t 查笔头位置）；CamKey 相机
（zoom 对数插值，差>4% 改绕不动点缩放）；`glyphBox` 用字形轮廓墨盒把"画的图形"与"渲染的
文字"对齐。
**最简**：L0 可做——折线表+弧长+一支笔；排线用 Canvas2D stroke。
**范例**：`open.ts`（笔→TikZ unicorn→PCB 化→滑入下一板）。

## 2. 图表→地形板（chart dive）
**适用**：讲"数据突变"，从抽象曲线跌进具象世界。
**构成**：发丝线图表（轴/刻度/mono 标签）→ 曲线悬崖 → 相机跟火花坠出图表 → 等高线 3D 地形。
**手法**：JS+GLSL 孪生高度场（同一函数供顶点位移/火花路径/相机贴地/标注，模板字符串内插
常量保证逐位一致）；fwidth 恒宽等值线+密时 fade-to-mean+Tanaka 坡向照明；球坐标 orbit 相机+
手工投影返回 (x,y,缩放,clip w) 供 2D 叠加；弹道反解（由"恰在 t 落到 y"反推加速度）；
标注是真的算出来的（牛顿迭代吸附等高线/梯度下降找极值）。
**最简**：L0 版=纯 2D 图表+镜头缩放坠落（等高线用预生成排线层）；L1 版=高度场 shader。
**范例**：`loss.ts`。

## 3. 输入框 token 板（prompt field）
**适用**：人机对话/祈求/发送——pre-chorus 式能量积蓄。
**构成**：黑暗场+一条输入框；唱词逐 token 打出；每 token 上方微缩"候选分布"弹窗；结尾回车
弹入下一板。
**手法**：token 切分表（词→piece+分布+pick，缺失回退）；弹窗三态（computing 闪烁
`hash(i,frameIdx)` → sampled 高亮指数衰减 → scaleY 坍缩）；UI 空间相机（Canvas2D setTransform
整层当相机，hairline=1/zoom）；Shot 表 {t,zoom,focus,blend}+锚点平滑跟随；回车时刻在拍网格
上量化。
**变体**：压迫收束（铁杠每拍合拢）/脆弱飘散（唱完字母漂移雪崩）——同一模板换背景与出口。
**最简**：L0 完全可做（本项目该板主体就是 Canvas2D）。
**范例**：`prompt.ts` + `prompt-data.ts`（数据驱动的玩笑分布）。

## 4. 字体猛击板（typographic slam）
**适用**：hook/口号——一词一拳，可重复使用且每次升级。
**构成**：全屏大字 slam + 数字仪表 + 每版不同出口。
**手法**：slam 原语（hold 爬近 × `1+amt(1−outExpo(0.16s))`）+ retrig（持留词每拍重 slam）；
punch 反相帧（每次 slam 2 帧前景背景互换）；速度驱动变形（`vel=|Δy|·60` → 纵向拉伸+多层
拖影）；odometer 滚数（clip 窗+detent+速度模糊）；帧级配色状态机（strobe/反白）；
"淡入前身份"（新元素从它上次出现的位置/字号 glide 过来）。
**最简**：L0 完全可做；出口交接见 transitions.md。
**范例**：`hook.ts`（4 版升级+四种出口协议）。

## 5. 线框房间板（wireframe room）
**适用**：空间叙事/多事件场景（爆炸→运镜→过生长），无 GPU 也有立体感。
**构成**：CPU 软件投影的发丝线 3D 房间 + 按平面分前后两组线批解决遮挡 + 贴在 3D 平面上的
Canvas2D 文字。
**手法**：pinhole 相机 `Cam{p,R,U,F,f}`+proj/近平面参数裁剪/深度衰减；`planeAffine`（投影 3 点
解仿射把 2D 文字贴上 3D 平面，自动吃透视与形变）；Shot+snap reframe（每拍重构图 outExpo 插值）
+roll 阻尼正弦；事件回溯冲击环（回溯最近 N 个十六分事件，双通道=shader 环带+顶点径向推移）；
表面生长（平面坐标"展开"映射到多个面，随机游走出界换面=沿墙爬）；伪运动模糊（超阈值时把
静态场景在过去 4 个时刻各画一遍）。
**最简**：L0 可做（CPU 投影本来就不需要 GPU）；线段上限几千段保帧率。
**范例**：`room.ts` + `room-geo.ts`（SegBuf 中间格式）。

## 6. 刻线生物板（engraved creature reveal）
**适用**：揭示/恐怖/宏大——一个"活物"从遮罩后显形。
**构成**：遮罩（面具/轮廓）占满画面 → 扫描带（前沿=卡拉OK光标）扫过处透明显形 → raymarch
刻线版画的生物（明暗即线密度）→ 标注/检测框等 UI 层。
**手法**：id 感知 smooth-min（聚合 SDF 时记录最近图元的参数坐标——刻线 UV 免费得到）；
half-res MRT G-buffer+深度/id 感知上采样（不连续度直接当沟壑墨线）；`elineLod` 密度 LOD
（log2 在两档线密度间 mix，任意距离屏幕线距恒定）；x-ray 扫描带与 wordProgress 联动；
眼睛=解析球求交（不受半分辨率限制）+开合弹簧。
**最简**：L1/L2 才有完整版；L0 降级=预生成排线贴图+遮罩位移（platform-videograph.md 降级表）。
**范例**：`shoggoth.ts` + `shoggoth-glsl.ts`（本库 raymarch 版画范本）。

## 7. 仪器板（instrument → cosmos 复合）
**适用**：从"测量"走向"失控"——示波器/仪表盘的克制开场接宇宙级失控。
**构成**：仪器屏幕（辉光轨迹+磷光余辉+刻度读数）→ 屏幕上某个形状变成奇点 → 透镜畸变吞掉
画面 → 流场/粒子世界。
**手法**：磷光余辉（前 N 拍旧轨迹按 0.5^k 重画+相位漂移）；束写文字（单笔画字+书写同步弧长）；
薄透镜方程反投影（`beta=θ(1−θE²/r²)`）+ **MipLayer**（mipmap+预乘纹理——畸变采样文字不闪的
关键）；预积分流场（init 一次积分成 Float32Array 查表=确定性 O(1)）；环上排字（proj 弦长缩放
+kern 修正+背面剔除）。
**最简**：L0 版=示波器+径向缩放坠落；L1 版=透镜 shader。
**范例**：`spacetime.ts` + `spacetime-lens.ts`。

## 8. 上升多乐章板（multi-movement match-cut chain）
**适用**：一段内讲完整上冲弧线：多个 10–20s 乐章硬切串联，每乐章一个材质世界。
**构成**：自由组合范式 1–17 的四个场景，靠 match-cut 缝合。
**手法**：**match-cut 屏幕锚定**（两镜头间缩放同时插值屏幕锚点，`cam.y=目标y−(H/2−sy)/zoom`，
让"同一物体"在切点前后屏幕位置不动）；鳞片刻线材质（Voronoi 单元穹顶法线+横贯等值线 hatch，
线随曲面弯、随光变宽）；guilloché 玫瑰线（斜率归一化距离保证线宽均匀）；圆柱图集滚轮
（`th=asin(y/R)`，图集 v=已转字位数−th/(2π/10)，模糊=角速度闭式抽头）；亮度域反白
（反白时保持高 chroma 强调色不变）。
**最简**：每个乐章各自用 L0 手法，match-cut 锚定是缝合关键。
**范例**：`ascent.ts` + ascent-eye/note/odo。

## 9. 纸面公文板（paper bureaucracy）
**适用**：反差段（全片唯一亮底）——表格/图章/技术图解的冷幽默。
**构成**：骨白纸+墨；打字机逐字；橡皮章砸落；技术图（MLP/架构图）脉冲；撕纸出板。
**手法**：**通道编码墨水**（Canvas2D 'lighter' 把多种墨画进 R/G/B 通道，shader 按通道调密度后
Beer-Lambert 叠印——墨叠墨的减色模型）；程序纸（fbm 云+纤维 SDF+斑点）；橡皮章墨（噪声砂眼+
受压 mottling+unsharp 边缘积墨；状态在 TS、质感在 shader——分离）；时间重映射 stutter
（`remap(t)→{tr,loop}` 把源区间快放 N 遍，内容无感知）；镜像词（逐 glyph scale(−1,1) 置镜像
kern 位置）；撕纸转场（三倍频锯齿线+飞丝+白纤维断口+两半坠落）。
**最简**：L0 版全可做（通道编码降级为直接分多次绘制不同"墨色"）。
**范例**：`bureau.ts`。

## 10. 地图/甘特板（map & schedule）
**适用**：计划/路线/评审的视觉幽默；等高线里藏第二图像（脸/标志）。
**构成**：静态底图（一次绘制：路线/里程碑/标注）+ 每帧程序化层（网格/地形/灼痕）+ 世界坐标
覆盖层。
**手法**：弧长路线函数（解析距离+弧长联合函数——灼痕=已过弧长阈值，age 驱动冷却色）；
**whip 在 shader 内 multi-tap**（快门内两个相机位姿间 ≤16 tap 各 shade 一次，tap 数=最大屏幕
位移自适应）；keystone 梯形透视+精确逆变换；构图反解（想让某物出现在屏幕某处→反解相机；
已知下一板锚点→反解本板末相机）；地形藏画（高度场=鼓包−特征槽，beat 波前以高斯环叠加进
标量场=等高线呼吸）；通道复用纹理（5 个词打包进 RGBA 4 通道+空间开关）。
**最简**：L0 版=底图 Canvas 预绘+灼痕重绘；whip 降级=多份偏移绘制。
**范例**：`leftturn.ts` + leftturn-map/gantt（甘特图"时间即坐标"+ease 反函数二分求途中事件）。

## 11. 无限晶格板（infinite lattice）
**适用**：催眠/失控复制——一个物体倍增填满世界。
**构成**：火花线弯成母体 → 按拍分裂（bit 位偏移树，部分副本旋转=编织排向）→ 相机 crane 下摆
进无限 raymarch 晶格 → 压合收尾（缝隙里挤满字）。
**手法**：**一份几何多端**（中心线常量表→CPU 画笔路径+GLSL SDF，`toFixed(5)` 模板注入保证逐位
一致；弧长区间截断="正在画的笔尖"）；2D SDF 升维（俯视时 `z=sqrt(r²−d²)` 当球冠着色，免
raymarch）；无限晶格四件套（单元 SDF+层堆叠只算最近层+解析跳空+像素尺度步进下限
`max(d·0.9, pr·(0.2+t·0.003))`）；按屏幕尺寸分级开闭软阴影/AO；显式频率足迹抗摩尔
（每像素线密度喂 hatch，超阈值退化为平均暗度）；缝隙高度由投影公式反推→字号自适应。
**最简**：L0 版=分裂 bit 树+预渲染母体贴图阵列；完整版需 L2。
**范例**：`paperclips.ts` + -geo/-glsl。

## 12. 燃烧路径板（burning path + instrument jam）
**适用**：不可逆进程（引信/导火索）+ 数据驱动的乐器视觉。
**构成**：编织纹理的线 → 燃烧前沿逐词推进，文字随经过而炭化 → 切第二世界（图表/乐器），
曲线由真实数据（音高/股价/任何序列）驱动形变。
**手法**：弧长-时间双向表（burnS(t)↔timeAtBurn(s) 互逆，每个字形的点燃/烧完时刻直接反查）；
编织纹理（两条反向螺旋+mod 定上下股）；destination-out 咬痕蚀刻（44 个不规则多边形按烧毁度
依次出现=腐朽文字）；init 期 ODE 积分成 Float32Array 查表（受迫弹簧跟踪音高+松手自由振铃——
**物理也服从纯函数时间观**）；smooth-min 构造受压弦形状；数据锚定歌词词起点（换 take 不改数据）+
从模拟自动检测地标（八度跳/颤音）驱动标注。
**最简**：L0 完全可做（燃烧=颜色阶梯+咬痕；弦=查表曲线）。
**范例**：`fuse.ts` + `fuse-pitch.ts`。

## 13. 无限堆叠板（infinite stack fall）
**适用**：递归/深渊结构——相机每拍坠落穿过一层。
**构成**：同一模块的无限重复（技术线稿），每拍一块，词随块落。
**手法**：Step[] 累积表（离散拍→连续位置；beat 步=springStep+拍前 anticipation 预移动）；
线稿模板+窗口（只画焦点 ±N 块=无限结构省 CPU）；程序化运动模糊（位移驱动的逐线段多次重画
α/NS）；R/G 通道卡拉OK纹理（填充写 R 描边写 G，shader wipe）；刚体错位块（变换闭包同时作用
mesh 矩阵与每条线段端点——线稿与实体共享运动）；"违抗卡拉OK"（高亮方向反着走）。
**最简**：L0 完全可做（Canvas2D 画 N 块线稿+逐帧平移）。
**范例**：`stack.ts` + `stack-kit.ts`。

## 14. 压强排版板（typographic pressure & tilt）
**适用**：密度/规模/失稳——排版本身承受压力。
**构成**：三连段：版面压强（安全框内逐拍压缩堆叠）→ 打破边框（框碎/标尺甩飞/QC log）→
世界歪斜（分步滚转+物件滚落+仪表救回）。
**手法**：离散字体轴跳变的隐藏（宽度档切换时用 `scaleX(上一级宽/当前宽→1)` 配 spring 弹回）；
副本文案双色平涂+hero 行 ink 色带遮底；框的物理（bow 弯曲/trip 闪光/recoil 断裂回缩/fragment
抛物线自旋）；DataTexture 文字 mask+全屏逆布局（不用几何画十万级重复单元，文字本身由单元拼出）；
`stepped(t,ks,freq,damp)` keyframed 弹簧（每拍阶跃被弹簧接住）+**低频副本=松动物件滞后差分源**；
stroboscopic 残影（按过去 N 帧状态各画一遍描边，交替双色）。
**最简**：L0 完全可做（本项目三段全是 Canvas2D/FSPass，无 3D）。
**范例**：`dense.ts` + dense-press/gpu/askew。

## 15. 生成树板（branching tree & recursion）
**适用**：概率/分支/自我嵌套——LLM 生成过程的视觉化。
**构成**：续写树（主线逐 token 写+分支按概率铺开）→ [MASK] 块逐词揭 → Droste 递归自嵌套。
**手法**：概率=线宽、层级=透明度的树布局；`tipX(t)` 单一进度源驱动 clip/相机/火花多消费者；
[MASK] 揭示（词 bbox 内残存色块+热扫描线+`[MASK]→word p=0.xx` 注）；**log-polar Droste**
（clog→复数乘→cexp+矩形归一化计数层+**解析导数喂 textureGrad** 防层缝模糊+底层直采实时渲染
的下一板=无缝切）；每帧重画的 CanvasTexture 当递归源；逐层 atlas 贴牌。
**最简**：L0 版=树+[MASK]；Droste 需 L1（shader）。
**范例**：`loom.ts` + loom-tree/loom-glsl。

## 16. 暗室氛围板（dark room, single light）
**适用**：留白/悬念段——一个光源讲完一切。
**构成**：raymarch 房间+唯一发光物（屏幕/灯），物体合拢/遮蔽把光逼成缝再逼成点 → 空间叙事
（剧院落幕）→ 光坍缩成交接点。
**手法**：解析矩形面光源 form factor（四角向量两两弧长和 /2π）+软阴影；体积光 pocket 采样
（采样集中在离光源最近的区间+hash 抖动）；emitRect 收窄发射区实现"光缝→光点"（面光源公式
自动跟随=物理正确）；逐材质刻线轴+世界间距；footprint 世界空间像素足迹喂 LOD；CPU 尘埃
（按 form factor+遮挡测试布点）；独立于 Scene 的可嵌套世界类（别的板可复用它做递归底层）。
**最简**：L0 降级=径向渐变光+剪影层+尘埃粒子。
**范例**：`ilya.ts` + ilya-room/ilya-glsl。

## 17. 终幕倒带板（finale & rewind loop）
**适用**：结尾爆点+循环闭合。
**构成**：数字爆表（放射线+冲击环+逐拍升级：破上限/对数尺/零之墙）→ 尾卡（公式排版+
字形形变链）→ Regenerate 按钮 → 倒带蒙太奇 → 倒放停在第一帧。
**手法**：相对拍坐标系（整场以"第几拍"写动画，不写秒）；字形轮廓形变链（textPathCommands+
flatten→点集仿射/逐点映射，填充与线条共享同一 transform；落地闪光冷却 `heat(k0,tau)`；
echo=取过去若干帧的 transform 各画一遍）；分数拆分（半平面 clip 两份拷贝分离+taffy 丝连接+
断点爆花）；倒带双轨（预渲染静帧 JPEG 加速倒放+shader 旧化 duotone/RGB 分离=廉价；
第二场景实例+手工构造 Frame 倒放刹车=昂贵但真）；crop-mark 画框首尾呼应。
**最简**：L0 完全可做（形变/倒带都可以纯 Canvas2D）。
