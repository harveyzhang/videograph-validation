# 逐阶段检查清单

每一步都要“看图”，不以接口返回成功代替检查。

| 阶段 | 检查 | 方法 |
|---|---|---|
| 定妆 | 三视图是同一个人；服饰、发式、标志物符合设定；无文字水印 | 拼成一张总览图逐个看 |
| 关键帧 | 人物与设定图一致；该空白的物件确实空白；主体在 16:9 安全区 | 17 张拼图总览 |
| 视频 | 人物不变形、不换脸；动作与提示一致；无字幕水印 | 每段抽 4 帧（每秒 1 帧）拼条 |
| 配音 | 每句时长放得进对应镜头 | ffprobe 时长对照分镜 |
| 配乐 | 段落起伏与剧本情绪一致；结尾是否按要求硬切 | 波形 + 频谱图 |
| 工程 | 规划切点与分镜一致；全部镜头/转场 `ready` | `project_get`、validate |
| 叠层 | 字不压脸、亮底上的字可读、横幅避开头部、标题有托底 | 每镜静帧（视频镜头用视频帧，不用关键帧） |
| 节奏 | 画面峰在拍上的比例；高能段是否有“死区”；闪烁 ≤ 3 次/秒 | `project_rhythm_report` |
| 成片 | 时长精确、音视频流齐全；每 2 秒一帧无出画/空帧/错字 | ffprobe + 带时间码的抽帧总览 |
| 意见 | 只改被点名的镜头；响应状态为 responded；导出闸门在人采用后才放行 | `project_get` 看 feedback 状态 |

听觉部分（配音音色、配乐好不好听、音画同步）AI 无法自查，交付时明确请用户带声音完整看一遍。
