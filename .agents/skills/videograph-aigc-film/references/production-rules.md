# 制作规则与交付说明

## 授权与版权

- 用户要做真实品牌的广告、要求“去网上找素材”时，先问用途与授权（一个问题，三选一）：
  1. 作品集/内部样片：自建素材，不下载品牌图片，不放品牌 logo，片尾注明“概念片 · 非官方”；
  2. 有品牌授权：用户提供授权素材（产品图、logo、3D 模型）的本地路径；
  3. 改成虚构品牌：自建素材，可自由发布（提醒用户发布前查商标重名）。
- 不下载网上的版权图片、视频、音乐拼进成片；不使用真实人物肖像。
- 字体用 OFL 等可商用许可（Noto Sans SC / Noto Serif SC 实测可用），不用来源不明的书法字体。

## 密钥

- 只存工作目录 `.env`；请求日志不写密钥；不进任何 git 仓库（工作目录放在仓库之外）。
- 对话里出现过的明文密钥，交付时建议用户轮换。

## 额度

- 先各试 1 张图、1 段视频，确认格式与质量后批量。
- 日志逐条记录 `kind/model/out/id/耗时/usage`，供用户对账。
- 密钥中途失效：停止提交 → 告知用户 → 用关键帧兜底把整片跑通 → 恢复后按任务 ID 续取已提交的任务 → 只补生成缺的。

## 剧本差异

常见：标称时长与时间码不一致、同一句台词前后写法不同、某个效果在技术上无法照做（移动物件上贴字）。处理：选更完整/一致的那个先做，交付说明“与剧本的差异”一节逐条写，并给出改回的成本。

## 交付说明模板

```
成片：<路径>（分辨率 · 帧率 · 时长 · 带音轨）
工程：<审阅室工程名>（N 镜 / M 转场，验证状态）
制作链路：定妆（模型）→ 关键帧（模型，数量）→ 视频（模型，数量）→ 配音（模型）→ 配乐（来源）→ 合成（VideoGraph）
自查：节奏报告要点；抽帧检查结论
与剧本的差异：…
需要用户处理：意见采用、密钥轮换、未提交的仓库改动、商标核查 …
```
