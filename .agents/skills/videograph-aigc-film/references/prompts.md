# 提示词模板

## 画风前缀（所有图像共用）

日漫二次元电影风（实测效果稳定）：

```
日本动画电影画风（新海诚式电影光影与色彩，赛璐璐上色，细腻背景美术，体积光与粒子），电影宽银幕构图，16:9，不要任何文字、字幕、水印。
```

换画风只换这一段，并在全片保持不变。

## 定妆设定图

```
日本动画电影画风（二次元赛璐璐上色，新海诚式电影光影，干净线条，精致细节），角色设定稿：白色背景，同一人物的正面全身、侧面全身、背面全身三视图并排，右上角两个表情特写；不要文字、不要水印。
角色：<年龄、体型、发型、神态；服装分件写清颜色与材质；随身标志物>
```

- 尺寸 1536×1024，`quality: high`。一次一角色，并行生成，逐张看图。
- 现代主角要写清“每一件衣服”（连帽外套颜色、T 恤、裤子、鞋、背包），后面所有镜头才会稳定。

## 关键帧

```
<画风前缀>
画面：<景别（特写/近景/中景/远景/航拍）>，<地点与时间光线>，<人物在做什么、朝向>，<前中后景元素>，<色调对比>。
人物必须与参考设定图完全一致（<角色名>：发型、面孔、服装、配饰都不能变）。
画面主体放在中央偏上的 16:9 安全区内（上下边缘会被裁掉）。
```

- 带 `refs`（设定图）走 `/v1/images/edits`。
- 需要引擎贴字的物件写“空白、无字”：如“泛黄的空白竖长愿签”“屏幕是纯黑发亮的空白（不要任何界面、图标和文字）”“地图正中央留出一块空白区域”。
- 要贴界面的手机：写“手机屏幕正对镜头、几乎与画面平行、竖直摆放、四个角清楚可见”——之后可用像素检测直接求出屏幕矩形，无需透视变换。

## 运动（图生视频）

```
<主体动作>，<环境动态（风、灯笼、车流、光尘）>，<运镜（缓推/跟随/横移/固定）>。日本动画电影画风，保持首帧的人物造型与画风不变，动作自然流畅，电影感运镜，不要出现任何文字。
```

- 一段只写一个动作 + 一个运镜；“走着走着停下回头”这种两段动作放在 5 秒以上的片段里。
- 古今转换类（现代城市变成古代长安）在一个片段里写“逐渐变化为”，实测可用。
